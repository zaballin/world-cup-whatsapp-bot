# Google Sheet Structure

The bot reads from a Google Sheet that must have these exact tabs and columns.

## Required Tabs

### 1. `Leaderboard`
The main data source for the pool standings.

| Column | Description |
|---|---|
| `Rank` | Current position (1, 2, 3...) |
| `Player` | Full name |
| `Nickname` | Short name for display in WhatsApp |
| `Points` | Total accumulated points |
| `Previous Rank` | Position before last update |
| `Movement` | Rank change (positive = up, negative = down) |
| `Daily Points` | Points earned today |
| `Correct Picks` | Total correct predictions |
| `Wrong Picks` | Total wrong predictions |

### 2. `Bot_Daily_View`
Bot-ready facts for the daily message. Generated by formulas or manually.

| Column | Description |
|---|---|
| `Field` | Field name |
| `Value` | Field value |

Supported fields:
- `date` — today's date
- `leader_name` — nickname of the leader
- `leader_points` — points of the leader
- `second_place_name`
- `second_place_points`
- `third_place_name`
- `third_place_points`
- `biggest_climber` — nickname of who moved up the most
- `biggest_climber_movement` — e.g. "+5"
- `disaster_of_day` — who had a bad day
- `disaster_reason` — why
- `last_place`
- `last_place_points`
- `matches_finished_today`
- `matches_tomorrow`
- `update_title`
- `roast_level`
- `tone`

### 3. `Matches` (optional, for match listing)
| Column | Description |
|---|---|
| `Match ID` | Unique identifier |
| `Slot A` | Team slot A identifier |
| `Slot B` | Team slot B identifier |
| `Status` | `pending` or `finished` |
| `Points` | Points for correct prediction |

### 4. `Players` (reference)
| Column | Description |
|---|---|
| `Player ID` | Unique ID |
| `Name` | Full name |
| `Nickname` | Short name |
| `Active` | `true` or `false` |

## Google Sheets API Setup

1. Create a Google Cloud project
2. Enable Google Sheets API
3. Create a Service Account
4. Share the spreadsheet with the service account email (as viewer)
5. Set env vars in `.env`:

```
GOOGLE_SHEET_ID=your_sheet_id_here
GOOGLE_SERVICE_ACCOUNT_EMAIL=your-service-account@your-project.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n..."
```

The `GOOGLE_PRIVATE_KEY` must have `\n` literal newlines preserved in the env var.
